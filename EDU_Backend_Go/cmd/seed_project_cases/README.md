从 Go 后端配置目录运行：

```bash
go run ./cmd/seed_project_cases
go run ./cmd/seed_project_cases --apply --backup /absolute/path/new-backup.sql.gz
```

默认只读；实际执行必须先成功备份。不会 AutoMigrate。四个项目在同一个事务中经现有手册和项目发布检查后发布，失败整批回滚；MySQL 命名锁避免并发重复执行。需要有效管理员和已经发布、镜像配置完整的提示词工作台。

固定 slug 已存在时不覆盖教师编辑；结构冲突报错。重复运行仍要求备份，不删除用户数据。不伪造报名人数、挑战数量或验收成绩。无须重启后端或重建前端。

本次只在 42 执行，35 不变。后续专属应用、独立封面、专属镜像及完整业务验证单独实施。

验证：`go test ./cmd/seed_project_cases`，覆盖只读预览、双语完整性、独立手册ID、镜像复用、幂等和发布失败回滚。
