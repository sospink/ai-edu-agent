# Lab Case Walkthrough

The platform currently has two major lab cases: Classic Lab and OpenClaw. They have different entry points, runtimes, and acceptance methods.

## Case 1: Classic Lab Course Practice

Classic Lab is used for course lessons, normal project units, and assignment resources.

### Flow

```text
Student enters lesson
→ Opens Agent manual
→ Creates Lab session
→ Go backend checks quotas and lab templates
→ K8S creates Pod / Service
→ Frontend shows noVNC, terminal, IDE, or gateway
→ Student performs the task
→ Agent validates through K8S exec
→ Student submits assignment or completes lesson
```

### Key Capabilities

- Every session has a record and expiration time.
- Creation, ready, execution, stop, error, and janitor cleanup write runtime events.
- Admins can view sessions, logs, events, and stop sessions idempotently.
- Quotas can control concurrency and duration by user, class, or global scope.

## Case 2: OpenClaw Project Practice

OpenClaw is used for observing enterprise-style Agent workflows.

### Flow

```text
Student enters OpenClaw project
→ Backend derives a project session key
→ Student sends a task or selects a scenario
→ Agent enters thinking
→ Agent calls tools and enters executing
→ Completed view shows final messages, artifacts, and metrics
→ Student views or downloads results
```

### Key Capabilities

- It does not create a K8S Classic Lab session.
- It connects to real external flows through OpenClaw Gateway and Feishu.
- Admins observe configuration and health.
- The first version is not governed by Classic Lab quota enforcement.

## Teacher Acceptance

Teachers can evaluate lab outcomes from three angles:

- Assignment submissions: submissions, attachments, evidence snapshots, and rubric items.
- Agent observability: step heatmaps, failed attempts, AI chats, and terminal events.
- Gradebook: class-level grades, status, and publish state.

## Admin Governance

Admins focus on:

- K8S runtime namespace health.
- Expired or abnormal Lab sessions.
- Quota blocks and quota pressure.
- Disabled or missing Lab templates.
- OpenClaw / Feishu availability.
- Audit logs for key operations.
