# Using Learning Center

The learning center is the starting point for students. Its route is `/study`. It now connects real learning outcomes, class courses, assignments, and the learner leaderboard.

## Page Areas

| Area | Description |
| --- | --- |
| Welcome and Level | From `/api/learning/overview`, showing level, milestones, and progress |
| Course Stats | Available courses, completed courses, and in-progress courses |
| Last 7 Active Days | Shows recent learning activity |
| Learner Leaderboard | From `/api/users/student-leaderboard` |
| Class Tabs | Shows student classes and the public exploration entry |
| Assignments | Shows class assignments, submissions, and feedback |
| Explore | Shows published platform courses, not necessarily teacher-assigned content |

## Learning a Course

1. Select a course from Explore or class courses.
2. Open course details and review stages, lessons, difficulty, and duration.
3. Read theory lessons directly.
4. Open Agent manuals and Classic Lab for lab lessons.
5. Completion writes learning records and updates the learning overview.

## Class Courses and Public Courses

Class courses are formal assignments from teachers. Public courses are published platform courses for free exploration. Only class courses or resources bound to assignments represent teacher-assigned work.

## Assignments and Feedback

After a teacher publishes an assignment, students can see it in the learning center. Assignments may bind courses, lessons, projects, OpenClaw scenarios, or manuals. After submission, teachers can grade, return, reopen, and publish grades. Unpublished grades are hidden from students.

## Learning Outcome Scope

The learning overview aggregates:

- Course and lesson completion.
- Learning streaks and recent 7-day activity.
- Assignment submissions, grading, and published grades.
- Agent step completion.

It is the first version of the learning outcome view, not a certificate or badge system.

## Common States

- No class: students can still browse public courses in Explore.
- No assignments: the current class has not published tasks yet.
- Lab creation failed: check quotas, lab templates, and K8S health first.
- OpenClaw unavailable: confirm the project has the `OpenClaw` tag and check OpenClaw / Feishu health.
