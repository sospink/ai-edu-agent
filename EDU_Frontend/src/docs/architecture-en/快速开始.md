# Quick Start

This page reflects the current Agent EDU Lab architecture. Older documents that describe a TypeScript backend and Docker-only runtime are historical references. The current platform is built around the Go backend and K8S Classic Lab.

## What the System Is

Agent EDU Lab is a three-portal platform for AI agent courses and engineering practice:

- Student portal: learning center, lessons, projects, Classic Lab, assignment submissions, and feedback.
- Teacher portal: classes, course and project management, publish checks, assignments, grading, gradebook, and the Agent observatory.
- Admin portal: users, classes, content governance, K8S session operations, quotas, audit logs, integration health, and AI settings.

## Local Startup

### Frontend

```bash
cd EDU_Frontend
npm run dev -- --host 0.0.0.0
```

Default URL: `http://localhost:3000`.

### Go Backend

```bash
cd EDU_Backend_Go
go run ./cmd/server
```

Default URL: `http://localhost:4000`. Health check:

```bash
curl -s http://localhost:4000/api/health
```

## Recommended Walkthrough

1. Open `/study` to view the learning center, learning overview, class courses, and assignments.
2. Enter a lesson to view theory content, Agent manuals, and lab entry points.
3. Open `/lab` for Classic Lab. The Go backend creates K8S Pods / Services and provides noVNC, WebSocket terminal, and K8S exec capabilities.
4. Open `/projects`. Project details and units enter Classic Lab through `/lab`.
5. Teachers use `/teacher/dashboard` for classes, assignments, grading, gradebook, and Agent observability.
6. Admins use `/admin/dashboard` for K8S runtime overview, quotas, audit logs, and configuration health.

## Important Boundaries

- `EDU_Backend_Go/` is the main backend.
- `EDU_Backend/` is the legacy TypeScript backend, used only for historical behavior and configuration reference.
- Classic Lab currently runs on K8S, not the old Docker admin surface.
- Courses and projects share the same K8S Classic Lab runtime.
- Course text, project descriptions, and manual content are content assets. Full bilingual support requires separate Chinese and English content.

## Development Checks

After frontend changes:

```bash
cd EDU_Frontend
npm exec tsc --noEmit
```

After Go backend changes:

```bash
cd EDU_Backend_Go
go test ./...
```

For integration work, add browser smoke checks, API health checks, and screenshots for key flows.
