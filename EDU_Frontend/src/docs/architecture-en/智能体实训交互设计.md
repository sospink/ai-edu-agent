# Agent Lab Interaction Design

The current Agent is not just a chat widget. It connects course content, lab runtime, step validation, teacher observability, and AI suggestions.

## Student Interaction

Students use Agent manuals inside lessons, projects, or labs:

1. Read the current step instructions.
2. Perform the task in K8S Classic Lab.
3. Trigger validation.
4. Request AI suggestions or code explanation when validation fails.
5. Completed steps are written to Agent progress and learning overview.

## Validation Flow

```text
Student clicks validate
→ POST /api/agent/verify
→ Agent service resolves the manual and step
→ Calls RuntimeBridge
→ Classic Lab runs commands through /api/lab/execute and K8S exec
→ Returns stdout / stderr / exit code / explanation
→ Writes step attempts and learning events
```

## AI Capabilities

Agent supports:

- Q&A and streaming Q&A.
- Code explanation.
- Validation failure suggestions.
- Prompt enhancement.
- Student FAQ reading.
- Reflection card generation and viewing.

The i18n flow passes `X-Locale` to the backend. AI prompts add language constraints for `zh-CN` or `en-US`.

## Teacher Observatory

The teacher portal `/teacher/agent-observatory` focuses on teaching process:

- View class × manual step heatmaps.
- Identify blocked students and failed steps.
- Inspect recent AI chats, validation attempts, and terminal events.
- Maintain step skill tags.
- Generate and publish FAQs.
- Record teacher interventions and view student reflections.

## FAQs and Interventions

FAQs are not directly visible to students by default. AI can generate drafts, but teachers must publish them. Teacher interventions are filtered by student and class permissions, so students only see their own pending interventions.

## Boundaries

- Agent suggestions do not replace teacher grading.
- Command output, code blocks, and user input are not translated by default.
- AI drafts should not become official feedback before teacher confirmation.
- Runtime validation depends on real Lab sessions and must not be replaced by fake frontend state.
