# Agent EDU Lab — OpenClaw 项目实训使用教程



## 一、功能概述

**OpenClaw** 是 Agent EDU Lab 平台中面向 AI Agent 实训的核心项目。通过 OpenClaw，您可以亲身体验一个真实 AI 智能体从「接收指令」到「思考规划」到「执行任务」到「交付产出」的完整工作流程。

**OpenClaw 四阶段工作流：**

> 场景选择（idle） → 思考中（running） → 执行中（approval） → 完成态（completed）

---

## 二、进入 OpenClaw 实训

### 步骤 1：点击导航栏「项目实战」

在平台任意页面，点击顶部导航栏中的 **「项目实战」** 菜单项，进入项目实战库。

![截屏2026-03-17 20.25.48](https://p.ipic.vip/8mulwm.png)

### 步骤 2：浏览项目列表

进入项目实战库后，您将看到所有可用项目的卡片列表。页面顶部提供：

- **搜索框** — 按项目名称、技术栈或方向搜索
- **标签筛选** — 按标签分类筛选项目（如「AI Agent」「全栈开发」等）

每个项目卡片展示：
- 项目封面图（悬停时有 3D 翻折动效）
- 项目名称和简介
- 难度标签（初级 / 中级 / 高级）
- 技术标签和预计时长



### 步骤 3：选择 OpenClaw 项目

在项目列表中找到 **OpenClaw 实训项目**，点击进入项目详情页。

![截屏2026-03-17 20.26.21](https://p.ipic.vip/puqiba.png)


![截屏2026-03-17 20.26.36](https://p.ipic.vip/qf0zme.png)

### 步骤 4：进入项目详情页

项目详情页展示 OpenClaw 的完整信息：

| 区域 | 说明 |
|:-----|:-----|
| **顶部大图** | 项目封面和基本信息 |
| **项目概述** | 项目目标、学习收获 |
| **单元列表** | 项目包含的实训单元（点击进入实训） |
| **技术标签** | 使用到的技术栈 |

**操作：** 点击单元列表中的实训单元，进入云端环境启动流程。系统将自动分配计算资源并启动 OpenClaw 实训环境。



### 步骤 5：等待环境启动

点击进入实训后，等待 5-15 秒即可进入实训工作区。

## 五、阶段一 — 场景选择（选择并启动）

### 5.1 选择工作场景

在右侧面板中浏览四个工作场景，通过左右箭头翻页选择您感兴趣的场景。

### 5.2 点击「开始工作」

选定场景后，点击底部的 **「▶ 开始工作」** 按钮。系统将：

1. 读取该场景的预设提示词
2. 自动跳转到「思考中」阶段
3. 在对话框中预填充指令内容

## 六、阶段二 — 思考中（发送指令与对话）

### 6.1 页面布局

思考中页面采用左右分栏：

| 区域 | 说明 |
|:-----|:-----|
| **左侧 · AI 对话区** | 与 OpenClaw Agent 实时对话 |
| **右侧 · 提示词引擎** | 提示词增强工具，优化指令质量 |

![截屏2026-03-17 20.29.52](https://p.ipic.vip/fnvpzt.png)



### 6.2 发送指令

对话区底部的输入框中已预填充了场景提示词。您可以：

1. **直接发送** — 点击发送按钮（↑）或按 Shift+Enter 发送预填充的指令
2. **修改指令** — 在输入框中编辑和调整指令内容后再发送
3. **语音输入** — 点击麦克风图标，通过语音识别输入指令

### 6.3 查看 Agent 回复

发送指令后，OpenClaw Agent 会通过飞书通道接收指令并开始处理。在对话区中可以看到：

- **Agent 头像** — 流光 AI 球体动画，表示 Agent 活跃状态
- **流式文字** — Agent 回复以逐字显现的方式呈现，支持 Markdown 富文本（表格、列表、代码块等）
- **用户消息** — 您发送的消息带弹跳动画效果

![截屏2026-03-17 20.31.02](https://p.ipic.vip/60cu5f.png)

### 6.4 使用提示词引擎

右侧的 **智能提示词引擎** 可以帮助您优化指令质量：

| 步骤 | 操作 |
|:-----|:-----|
| 1 | 在输入框中粘贴或输入初始提示词 |
| 2 | 点击 **「✨ 增强提示词」** 按钮 |
| 3 | 系统通过 AI 自动优化提示词 |
| 4 | 优化结果以 **Markdown 预览** 形式展示 |
| 5 | 点击 **「编辑」** 可手动修改优化结果 |
| 6 | 点击 **「复制」** 将优化后的提示词复制到剪贴板 |
| 7 | 粘贴到左侧对话框中发送给 Agent |

## 七、阶段三 — 执行中（监控 Agent 工作过程）

当 Agent 开始执行任务后，状态自动切换到「执行中」阶段。

| 区域 | 说明 |
|:-----|:-----|
| **左侧 · 执行日志时间线** | 实时展示 Agent 的每一步操作 |
| **右侧 · 实时决策分析** | Agent 当前决策和工具链状态 |

![截屏2026-03-17 20.37.23](https://p.ipic.vip/n3spxm.png)

### 7.2 执行日志时间线

左侧面板以垂直时间线的形式展示 Agent 的执行事件。每条事件包含：

| 元素 | 说明 |
|:-----|:-----|
| **时间线节点** | 圆形标记，表示事件序列 |
| **事件类型标签** | 彩色标签标识事件类型 |
| **事件名称** | 当前执行的操作名称 |
| **时间戳** | 事件发生时间 |

**事件类型颜色对照：**

| 颜色 | 类型 | 说明 |
|:-----|:-----|:-----|
| 🔵 天蓝色 | 用户输入 | 您发送的指令 |
| 🟠 琥珀色 | 工具调用 | Agent 调用外部工具 |
| 🟣 紫色 | 工具输出 | 工具返回的结果 |
| 🟢 翡翠绿 | Agent 回复 | Agent 的分析和总结 |
| 🔴 玫红色 | 错误 | 执行异常或报错 |

**查看 Agent 回复详情：** 对于 Agent 回复类事件，默认折叠显示。点击 **「📩 查看回复内容」** 按钮，可展开查看完整的 Markdown 渲染内容（包括表格、代码块、列表等）。

## 九、完整操作流程总结

1. 导航栏点击「项目实战」
2. 找到 OpenClaw 项目卡片并点击
3. 项目详情页 → 点击实训单元进入
4. 等待环境启动（5-15 秒）
5. 进入实训工作区
6. 【场景选择】翻页选择工作场景 → 点击「开始工作」
7. 【思考中】查看 / 修改预填指令 → 发送给 Agent
8. 【思考中】可选：使用提示词引擎优化指令
9. 【执行中】监控 Agent 执行日志和决策分析
10. 【执行中】点击「查看回复内容」展开 Agent 回复详情
11. 【完成态】查看执行指标和产出物
12. 【完成态】下载构建产物文件
13. 点击顶部「完成实验」结束实训

## 十、常见问题

| 问题 | 解答 |
|:-----|:-----|
| 选择场景后指令在哪里？ | 点击「开始工作」后，指令会自动预填到思考中页面的对话输入框中 |
| 可以修改预填充的指令吗？ | 可以。在发送前，可以自由编辑输入框中的指令内容 |
| Agent 回复太长怎么办？ | 执行日志中的 Agent 回复默认折叠，点击「查看回复内容」展开查看 |
| 执行中途可以取消吗？ | 当前版本不支持中途取消，建议等待 Agent 执行完毕 |
| 产物文件如何下载？ | 在完成态页面的产物列表中，直接点击文件卡片即可下载 |
| 可以重新开始吗？ | 可以返回场景选择，重新选择场景并发送新的指令 |
| 提示词引擎的作用是什么？ | 它利用 AI 优化您的指令，使 Agent 能更精准地理解需求，提升执行效果 |
| 为什么看不到执行日志？ | 请确认 Agent 已开始执行任务（状态已切换为「执行中」），日志会实时推送 |

通过 OpenClaw 实训，您将获得以下能力提升：

| 收获 | 说明 |

| ✅ 理解 Agent 工作原理 | 通过四阶段流程，直观理解 Agent 如何拆解和执行复杂任务 |
