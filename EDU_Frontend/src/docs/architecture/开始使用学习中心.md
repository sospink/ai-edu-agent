# Agent EDU Lab — 学习中心使用教程



## 一、功能概述

学习中心是 Agent EDU Lab 的核心学习模块。您可以在此浏览所有可用技能课程，按阶段推进学习进度，并完成理论知识学习与云端实训操作。

**学习路径总览：**

> 导航栏「学习中心」 → 技能列表 → 选择课程 → 课程详情页 → 选择课时 → 理论课（知识型） / 实训课（实操型）

---

## 二、进入学习中心

### 步骤 1：点击顶部导航栏

在平台任意页面，点击顶部导航栏中的 **「学习中心」** 菜单项，即可进入学习中心首页。

![截屏2026-03-17 20.08.00](https://p.ipic.vip/2868gb.png)

---

## 三、技能列表页

进入学习中心后，您将看到技能列表页，页面分为三个区域：

### 3.1 顶部 — 学习 Dashboard

页面顶部展示您的学习概览数据：

| 区域 | 说明 |
|:-----|:-----|
| **里程碑进度** | 当前等级、下一个里程碑目标（完成 5 门课程、连续学习 7 天） |
| **学习统计** | 可学课程数、已完成数、进行中数，以及每日打卡日历 |
| **排行榜** | 学习社区排名，激励您持续学习 |

![截屏2026-03-17 20.09.35](https://p.ipic.vip/uehu3l.png)

### 3.2 中部 — 推荐学习

系统会推荐一门课程供您快速开始。卡片上展示课程名称、难度等级、技能数、课时数和预计时长。

**操作：** 点击 **「开始学习」** 按钮或卡片任意区域，即可进入该课程的详情页。

![截屏2026-03-17 20.10.12](https://p.ipic.vip/cg12oo.png)

### 3.3 下方 — 所有技能树

以网格形式展示平台所有已发布的技能课程。每张卡片包含：

- **课程图标和名称**
- **难度标签**（入门 / 进阶 / 高级）
- **课程规模**（技能数 / 课时数 / 预计时长）

**操作：** 点击任意课程卡片，进入该课程的详情页。

![截屏2026-03-17 20.10.57](https://p.ipic.vip/od8pag.png)

## 四、课程详情页

点击某个课程后，进入课程详情页。页面采用左右分栏布局。

### 4.1 页面头部

展示课程的核心信息：

- 课程图标（彩色大图标）
- 课程名称和详细描述
- 统计信息：技能数 · 课时数 · 预计时长 · 难度等级
- **「开始学习」** 和 **「分享技能树」** 两个操作按钮
- 左上角 **返回箭头** 可回到技能列表

### 4.2 左侧 — 课程大纲（阶段 + 课时）

课程内容按 **阶段（Stage）** 组织，每个阶段包含多个 **课时（Lesson）**。

#### 阶段卡片

每个阶段以彩色卡片呈现，上方标注难度等级标签（如「入门级」「进阶级」），下方显示阶段标题和描述。

#### 课时列表

阶段卡片下方是该阶段的课时列表。每个课时卡片展示：

| 元素 | 说明 |
|:-----|:-----|
| **类型图标** | 📖 文本 / 🏆 挑战 / ✅ 测验 / 🔬 实验 |
| **课时名称** | 课时标题 |
| **元信息** | 类型标签 · 预计时长 · 可获经验值（如 +50 XP） |
| **进度指示** | ⭕ 未开始 / ▶️ 进行中 / ✅ 已完成 |
| **开始按钮** | 鼠标悬停时显示「开始」按钮 |

**操作：** 鼠标悬停到课时行上，右侧出现 **「开始」** 按钮，点击即可进入学习。

![截屏2026-03-17 20.11.45](https://p.ipic.vip/fergzs.png)

### 4.3 右侧 — 课程信息侧边栏

侧边栏包含四个模块：

| 模块 | 说明 |
|:-----|:-----|
| **课程信息** | 难度等级、总课时、预计时长、技能点 |
| **课程证书** | 完成所有课程后可解锁（当前为锁定状态） |
| **总体进度** | 可视化展示各课时的完成状态（绿色=已完成、蓝色=进行中、灰色=未开始） |
| **学习社区** | 加入讨论入口 |

![截屏2026-03-17 20.12.48](https://p.ipic.vip/gjblv6.png)

## 五、知识型课时（理论课）

当课时类型为 **「文本」** 时，点击「开始」将打开理论课页面。

### 5.1 页面布局

理论课页面采用 **左右分栏** 布局，中间可拖拽调节宽度：

| 区域 | 说明 |
|:-----|:-----|
| **左侧 · 资料列表** | 展示该课时的所有学习资料，支持折叠/展开 |
| **中间 · 资料阅读区** | 渲染选中的资料内容 |
| **右侧 · AI 助教** | Dify AI 助教对话窗口，可随时提问 |

![截屏2026-03-17 20.13.48](https://p.ipic.vip/uw24h9.png)

### 5.2 支持的资料格式

| 格式 | 图标 | 渲染方式 |
|:-----|:----:|:---------|
| **Markdown** | 📄 | Typora 风格渲染，支持代码高亮（VS Code 风格代码块，带复制按钮） |
| **PDF** | 📕 | 内嵌 PDF 阅读器，支持翻页、缩放、下载 |
| **Word (.docx)** | 📘 | 高保真文档预览，支持适配宽度/原始比例切换 |
| **思维导图** | 🧠 | 可视化思维导图渲染 |

**操作：** 在左侧资料列表中点击不同资料，右侧阅读区会切换显示对应内容。

![截屏2026-03-17 20.15.20](https://p.ipic.vip/thdbqo.png)

### 5.3 AI 助教

右侧 AI 助教面板会根据当前课时上下文自动初始化，您可以：

- 就当前学习内容向 AI 提问
- 获得概念解释和示例
- 请求练习建议

### 5.4 完成课时

学完资料后，点击页面中的 **「完成课时」** 按钮，弹出确认对话框，确认后该课时标记为已完成，获得对应 XP 经验值。

![截屏2026-03-17 20.15.20](https://p.ipic.vip/ve6euu.png)

## 六、实训型课时（云端实训）

当课时类型为 **「实验」「挑战」** 等实操类型时，点击「开始」将进入云端实训环境。

### 6.1 启动序列

进入实训后，平台会自动执行 **环境启动序列**：

1. 正在分配 K8S 运行资源（Allocating Runtime Resources）
2. 正在拉取实训镜像（Pulling Lab Image）
3. 正在创建 Pod 与 Service（Creating Pod / Service）
4. 正在配置 noVNC、Web Terminal、IDE 等访问入口
5. 正在建立安全连接与会话心跳

等待所有步骤完成后，自动进入实训工作区。

![截屏2026-03-17 20.18.19](https://p.ipic.vip/9di2m9.png)

### 6.2 实训工作区概览

启动完成后进入实训工作区，顶部有类似 VS Code 的标签栏，中央为内容区域。

**顶部工具栏说明：**

| 元素 | 说明 |
|:-----|:-----|
| **返回按钮** | 返回课程详情页 |
| **Tab 标签页** | 在不同环境间切换（见下方四种环境） |
| **计时器** | 显示实训剩余时间（默认 2 小时） |
| **状态指示** | CPU 状态和网络连接状态 |
| **完成实验** | 绿色按钮，完成实训后点击提交 |

### 6.3 四种实训环境

#### 环境一：Desktop（云端桌面）

提供完整的 Linux 图形桌面环境，通过 VNC 远程连接。您可以像操作本地电脑一样使用文件管理器、浏览器、文本编辑器等工具。

![截屏2026-03-17 20.19.05](https://p.ipic.vip/qx9n3y.png)



#### 环境二：Terminal（终端）

提供 Web 终端，通过后端 WebSocket 桥接到 K8S exec。支持完整的 Linux Shell 操作，可运行 Python、Node.js 等命令。

![截屏2026-03-17 20.19.15](https://p.ipic.vip/7fwp3e.png)

#### 环境三：CLI Agent（命令行 Agent）

集成 AI 编程助手，可以通过命令行与 AI Agent 交互，获得代码建议和自动化辅助。

![截屏2026-03-17 20.19.23](https://p.ipic.vip/vdeptz.png)

#### 环境四：WebIDE（在线代码编辑器）

提供在线代码编辑器，类似 VS Code 的界面，支持语法高亮、文件管理和代码编辑功能。

![b52e7211932596a5356259a3efea05ab](https://p.ipic.vip/iokw45.jpg)

### 6.4 Agent 手册（实训步骤引导）

实训环境中内置了 **AI Agent 手册**，它是您完成实训的核心辅助工具。

**Agent 手册功能：**

| 功能 | 说明 |
|:-----|:-----|
| **步骤引导** | 列出当前实训的所有操作步骤，指引您按顺序完成 |
| **操作提示** | 每个步骤包含详细的操作说明和预期结果 |
| **进度跟踪** | 标记已完成的步骤，展示整体进度 |
| **智能对话** | 遇到问题时，可以向 AI 提问获得帮助 |

**使用方式：**

1. 进入实训环境后，Agent 手册面板位于界面中可查看
2. 按照手册中的步骤顺序执行操作
3. 完成某个步骤后，手册会自动标记进度
4. 遇到困难时，可以在对话区域向 AI 助教提问

![截屏2026-03-17 20.21.40](https://p.ipic.vip/clqnrg.png)

![4a761a96b8266ddb7018139b4ae3183e](https://p.ipic.vip/r7165v.png)

### 6.5 完成实训

完成所有操作步骤后，点击顶部工具栏右侧的绿色 **「✅ 完成实验」** 按钮提交结果。系统会记录您的完成状态和获得的经验值。

## 七、学习进度管理

### 7.1 进度追踪

课程详情页右侧的「总体进度」面板会实时展示您的学习状态：

- 🟢 **已完成** — 绿色勾选标记
- 🔵 **进行中** — 蓝色播放标记
- ⚪ **未开始** — 灰色空心圆

### 7.2 推荐学习路径

| 步骤 | 操作 |
|:-----|:-----|
| 1 | 先完成理论课（文本类型），建立知识基础 |
| 2 | 进入实训课（实验/挑战类型），动手操作 |
| 3 | 善用 AI 助教，遇到问题及时提问 |
| 4 | 按阶段顺序推进，逐步提升难度 |
| 5 | 完成全部课时后，解锁课程证书 |

## 八、常见问题

| 问题 | 解答 |
|:-----|:-----|
| 实训环境启动失败怎么办？ | 点击页面中的「重试」按钮，或刷新页面重新启动 |
| 实训环境时间用完了怎么办？ | 实训环境默认 2 小时，到期后 K8S 会话会自动停止并进入清理流程，请在时间内完成操作 |
| 一个课时可以重复学习吗？ | 可以，已完成的课时可以再次打开复习 |
| AI 助教回答不准确怎么办？ | 尝试更详细地描述问题，或提供上下文信息 |
| 检测到已有实验环境怎么办？ | 系统同时只允许一个实训环境，选择「关闭并重新创建」即可 |
