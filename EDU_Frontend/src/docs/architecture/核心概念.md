# 核心概念

本文档介绍 Agent EDU Lab 平台设计中的核心概念与关键术语，帮助您建立对平台架构和教学理念的完整认知。

---

## 智能体 (Agent)

传统的大语言模型（LLM）只能被动地接收问题并生成文本回答。而 **Agent（智能体）** 则是一种具备自主行动能力的高级模型封装形式——它通过「规划 → 观察 → 调用外部工具 → 反馈调整」的循环机制来自主完成复杂任务。

在 Agent EDU Lab 平台中，智能体主要扮演两个角色：

| 角色 | 驱动技术 | 核心能力 |
|:-----|:---------|:---------|
| **AI 教师** | Dify 工作流 + 课时上下文注入 | 步骤化引导、操作验证、进度推进 |
| **OpenClaw Agent** | 飞书 Bot + 外部工具链 | 自主任务执行、多工具调度、产出交付 |

---

## 课时感知 AI (Context-Aware AI)

这是 Agent EDU Lab 最核心的技术创新之一。

传统在线学习平台的 AI 助手无论在哪个页面，给出的都是千篇一律的"你好，有什么可以帮你的？"。**课时感知 AI 能够动态感知学生当前所在的课程、阶段和课时**，自动调整教学内容和引导策略。

**工作原理：**
当学生进入某节实训课时时，前端会将当前的课程 ID、课时 ID、学生信息和实训步骤上下文一并传递给 Dify AI 引擎。AI 教师据此生成与当前课时精准匹配的教学内容——不同课时看到的开场白、引导步骤和验证逻辑完全不同。

---

## 云端沙箱 (Cloud Sandbox)

每个实训环节为学生分配的独立、隔离的 Docker 容器实例。学生无需在本地安装任何开发工具或配置环境，打开浏览器即可获得一个功能完整的云端工作区。

**沙箱包含以下核心组件：**

| 组件 | 技术实现 | 用途 |
|:-----|:---------|:-----|
| **远程桌面 Desktop** | VNC 图形化连接 | 操作 GUI 应用、使用浏览器类工具 |
| **终端 Terminal** | WebTTY 实时连接 | 执行命令、运行脚本、查看日志 |
| **代码编辑器 IDE** | Web 嵌入式 IDE | 在线编写和调试代码 |

**生命周期管理：** 沙箱与后端通过双向 WebSocket 建立心跳保活连接。如果学生断开连接超过 15 分钟，系统会自动冻结容器数据并进入挂起状态以节约集群资源。下次进入时可自动恢复到断开前的工作状态。

---

## 步骤化实训 (Step-by-Step Training)

Agent EDU Lab 的实训课程不是简单地"布置作业让学生自己做"，而是将每个复杂任务拆解为一系列有序的、可验证的操作步骤。

**每个实训步骤包含：**
- **步骤描述**：清晰说明需要完成什么操作
- **操作指令**：AI 教师给出具体的终端命令或操作指南
- **验证规则**：系统自动检查操作结果是否符合预期（基于正则匹配、AST 分析或命令返回值）
- **反馈机制**：验证通过则自动推进；验证失败则给出精准的错误诊断和修复建议

这种设计确保了：学生不是"看完即完成"，而是"做对才算过关"。

## 课程结构体系

Agent EDU Lab 采用四层结构化的课程组织方式：

| 层级 | 说明 | 示例 |
|:-----|:-----|:-----|
| **技能 (Skill)** | 一个可学习的能力方向 | Dify 智能体开发 |
| **课程 (Course)** | 围绕某个技能的完整学习路径 | 从零构建 Dify 工作流 |
| **阶段 (Stage)** | 课程中的学习阶段 | 入门基础 / 进阶实操 / 综合实战 |
| **课时 (Lesson)** | 最小学习单元，分为理论课和实训课 | Docker 容器网络配置（实训课） |

每节课时可配套一份 **AgentManual（AI 教师手册）**，其中定义了该课时的 AI 引导步骤、验证命令和期望输出。

## OpenClaw 全景演练

OpenClaw 是 Agent EDU Lab 的旗舰实训模块，也是平台最具创新性的功能。它将一个真实的企业级 AI Agent 工作流完全透明化，让学生以"上帝视角"观察和参与 Agent 的完整生命周期。

**四个核心阶段：**

1. **场景导入 (Idle)**：浏览预设业务场景，选择感兴趣的任务类型
2. **人机协作 (Thinking)**：向 Agent 发送指令、优化提示词、观察思考过程
3. **可观测执行 (Executing)**：实时监控 Agent 的工具调用、任务管线和执行进度
4. **成果交付 (Completed)**：查看结构化产出物、回顾执行流程、评估工作质量

OpenClaw 通过 **飞书即时通讯 Bot 通道** 实现与 Agent 的实时交互，展示了 AI Agent 如何真正接入企业级通讯系统——这不是模拟演示，而是真实的生产级工程实现。

---

## 项目实战 (Project)

区别于课时级别的单步实训，项目实战模块提供更接近真实工作场景的工程级任务。

每个项目由多个 **单元 (Unit)** 组成，采用「闯关驱动」的推进模式。学生需要按顺序完成各个单元的交付任务，模拟企业中多步迭代的交付过程。每个单元可联动云端实训环境进行实际的代码编写和部署操作。

---

## 全局 Copilot

平台全站右下角悬浮的 AI 助手组件，由通义千问（Qwen）大语言模型驱动，基于平台知识库提供通用的智能问答能力。

与课时感知 AI 教师不同，全局 Copilot 不绑定具体课时上下文，更适合：
- 课前预习中的概念解释
- 跨课程的通用技术提问
- 课后复习中的知识点串联
- 编程实践中的代码疑问解答
