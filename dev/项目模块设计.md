2. 表关联逻辑与后端实现指南
由于禁止了物理外键，所有的关联都需要你在后端代码（Service层）中逻辑处理。

关系图谱
项目与单元 (1:N)

关联字段: project_units.project_id => projects.id

后端实现:

查询详情页时，先查 projects 表拿到主信息。

紧接着用 SELECT * FROM project_units WHERE project_id = ? ORDER BY mode_group, sort_order 查出大纲。

在代码中将单元按 mode_group 分组，组装成前端需要的树形结构。

项目与标签 (N:M)

关联字段: project_tags 表连接 projects 和 tags。

后端实现:

新增/编辑项目时: 这是一个难点。前端传过来的是 tag_ids: [1, 2, 5]。你需要先删除该项目旧的关联 DELETE FROM project_tags WHERE project_id = ?，然后批量插入新的关联。

后端实现:
