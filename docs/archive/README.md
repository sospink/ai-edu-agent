# Archive

这里存放历史资料、旧计划、产品演示材料、迁移过程文档。

## 用途
- 保留历史上下文
- 保留旧方案和演示资料
- 在需要追溯时可查

## 不建议作为当前事实来源
以下问题不要优先依赖 archive 里的资料判断：
- 当前主架构是什么
- 当前主链路是否已经完成
- 当前应该改 Go 还是 TS
- 当前 Lab 是否仍然走 Docker
- 当前 OpenClaw 是否仍然走旧链路

这些问题应优先以以下资料为准：
- [AGENTS.md](../../AGENTS.md)
- [docs/START-HERE.md](../START-HERE.md)
- [docs/PROJECT-STATUS.md](../PROJECT-STATUS.md)
- [EDU_Backend_Go/docs/development-progress.md](../../EDU_Backend_Go/docs/development-progress.md)
- [EDU_Backend_Go/docs/ts-go-parity-matrix.md](../../EDU_Backend_Go/docs/ts-go-parity-matrix.md)
