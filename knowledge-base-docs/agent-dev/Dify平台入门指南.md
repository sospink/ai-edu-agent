# Dify 平台入门指南

## 什么是 Dify？

Dify 是一个开源的 LLM 应用开发平台，让你可以快速构建 AI 应用，无需复杂的编程。它提供了可视化的工作流编排、知识库管理、Agent 创建等功能。

## Dify 的核心功能

### 1. 应用类型

Dify 支持四种应用类型：

- **聊天助手 (Chat)**：基础对话应用，适合简单问答场景
- **文本生成 (Completion)**：单次输入输出，适合内容生成
- **Agent**：具备工具调用能力的智能体，可以执行复杂任务
- **工作流 (Workflow)**：可视化编排多个节点，实现复杂业务逻辑

### 2. 工作流节点类型

| 节点类型 | 功能说明 | 使用场景 |
|---------|---------|---------|
| 开始节点 | 接收用户输入 | 所有工作流必需 |
| LLM 节点 | 调用大语言模型 | 文本生成、对话 |
| 知识检索 | 从知识库检索相关内容 | RAG 应用 |
| 问题分类器 | 根据问题类型分流 | 多场景路由 |
| 条件分支 | IF/ELSE 逻辑判断 | 流程控制 |
| 代码执行 | 运行 Python/JavaScript | 数据处理 |
| HTTP 请求 | 调用外部 API | 集成第三方服务 |
| 变量聚合 | 合并多个变量 | 数据整合 |
| 回答节点 | 输出最终结果 | 所有工作流必需 |

### 3. 知识库配置

创建知识库的步骤：

1. 进入「知识库」菜单
2. 点击「创建知识库」
3. 上传文档（支持 PDF、Word、Markdown、TXT 等）
4. 选择分段方式和 Embedding 模型
5. 等待索引完成

**最佳实践：**
- 文档内容要结构清晰，使用标题分层
- 每个知识库聚焦一个主题
- 定期更新和维护知识库内容

### 4. Prompt 模板设计

好的 Prompt 模板应该包含：

```
## 角色定义
你是一个专业的 [角色]，擅长 [能力]。

## 任务说明
你需要根据用户的问题，[具体任务]。

## 约束条件
1. [约束1]
2. [约束2]

## 输出格式
请按照以下格式回答：
- 要点1
- 要点2

## 上下文
{{#context#}}

## 用户问题
{{#query#}}
```

## 创建第一个 Agent

### 步骤 1：创建应用
1. 点击「创建应用」
2. 选择「从空白创建」
3. 选择「Agent」类型
4. 填写应用名称和描述

### 步骤 2：配置模型
1. 选择基础模型（如 GPT-4、Claude 等）
2. 设置温度参数（0-1，越低越确定）
3. 配置最大 Token 数

### 步骤 3：添加工具
1. 点击「添加工具」
2. 选择内置工具或自定义工具
3. 配置工具参数

### 步骤 4：编写系统提示词
定义 Agent 的角色、能力和行为规范。

### 步骤 5：测试和发布
1. 在预览区测试对话
2. 调整参数直到满意
3. 点击「发布」

## 常见问题

**Q: 如何让 Agent 记住上下文？**
A: 在 LLM 节点中启用「对话记忆」，设置记忆窗口大小。

**Q: 知识库检索不准确怎么办？**
A: 1) 优化文档分段 2) 调整相似度阈值 3) 使用更好的 Embedding 模型

**Q: 如何调试工作流？**
A: 使用「运行日志」查看每个节点的输入输出，定位问题。
