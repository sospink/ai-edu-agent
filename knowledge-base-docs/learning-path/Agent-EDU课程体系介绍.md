# Agent EDU 课程体系介绍

## 平台简介

Agent EDU 是一个专注于 AI Agent 智能体开发的在线教育平台，提供从入门到精通的完整学习路径。

## 课程体系

### 🌱 入门课程

#### 1. AI 基础认知
**适合人群：** 零基础小白
**学习时长：** 8 课时
**课程内容：**
- AI 发展历史和现状
- 大语言模型原理简介
- ChatGPT、Claude、文心一言等产品体验
- AI 应用场景分析

**学习成果：**
- 理解 AI 基本概念
- 能够使用主流 AI 产品
- 了解 AI 的能力边界

---

#### 2. Prompt Engineering 入门
**适合人群：** 有 AI 产品使用经验
**学习时长：** 12 课时
**课程内容：**
- Prompt 的基本结构
- 角色设定技巧
- 输出格式控制
- Few-shot 学习
- 常见 Prompt 模板

**学习成果：**
- 能够编写有效的 Prompt
- 掌握常用 Prompt 技巧
- 能够优化 AI 输出质量

---

### 🚀 进阶课程

#### 3. Dify 平台实战
**适合人群：** 完成入门课程
**学习时长：** 16 课时
**课程内容：**
- Dify 平台介绍和安装
- 聊天助手应用创建
- 工作流编排详解
- 知识库配置和优化
- Agent 应用开发
- API 发布和集成

**实战项目：**
- 智能客服 Bot
- 文档问答助手

**学习成果：**
- 熟练使用 Dify 平台
- 能够创建复杂工作流
- 掌握知识库配置技巧

---

#### 4. Coze 扣子开发
**适合人群：** 完成入门课程
**学习时长：** 12 课时
**课程内容：**

- 工作流设计
- 多平台发布

**实战项目：**

**学习成果：**
- 熟练使用 Coze 平台
- 能够快速创建 Bot
- 掌握插件使用技巧

---

#### 5. RAG 知识库开发

**实战项目：**

**学习成果：**
- 理解 RAG 完整流程

## 学习路径推荐

### 路径一：零基础快速入门
```
AI 基础认知 → Prompt Engineering → Coze 开发 → 实战项目
预计时长：6-8 周
```

### 路径二：开发者进阶
```
Prompt Engineering → Dify 实战 → RAG 开发 → LangChain → 实战项目
预计时长：12-16 周
```

### 路径三：全栈 Agent 工程师
```
全部课程 + 多个实战项目
预计时长：6 个月
```
