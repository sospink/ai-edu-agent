# Agent 智能体开发学习路线

```
第一门：提示词工程
        ↓

        ↓
第三门：MCP Server 开发
        ↓
```

## 第一阶段：提示词工程

**对应课程：** 提示词工程

**核心目标：** 掌握工程化提示词思维，从"写提示词"升级到"构建提示词系统"

**学习重点：**
- 五大工程化原则：模块化、参数化、版本化、可测试性、可观测性
- 提示词模块化设计：角色模块、任务模块、约束模块、输出模块
- 参数化模板设计：抽象变量，一个模板多种用途
- 版本管理实践：记录修改原因和测试结果
- 测试用例设计：正向、边界、负向用例

**实战项目：** 万能文案生成器
- 支持小红书、微博、微信公众号、抖音、LinkedIn 五大平台
- 支持活泼可爱、专业权威、走心感人等多种风格
- 项目将五大工程化原则全部付诸实践

**前置要求：** 无，零基础可学

**预估学时：** 8-12 小时

**完成标志：** 独立完成万能文案生成器，能够清楚解释五大原则的意义

---

## 第二阶段：智能体框架与开发

**对应课程：** 智能体框架与开发

**核心目标：** 理解 Agent 运作原理，能够使用 LangChain/LangGraph 开发实用 Agent

**学习重点：**

Agent 基础概念：
- PRA 循环（感知-推理-行动）：Agent 的核心运作机制
- ReAct 模式：思考（Thought）→ 行动（Action）→ 观察（Observation）的循环
- 与普通 LLM 的区别：自主性、工具调用、记忆系统

工具调用：
- 如何定义工具（@tool 装饰器）
- 工具描述规范（让 AI 正确理解工具用途）
- 工具调用流程

记忆系统：
- 短期记忆（Session 内）
- 长期记忆（持久化到数据库）
- 工作记忆（任务中间状态）
- 语义记忆（向量检索）

框架选择：
- LangChain：链式调用，适合简单固定流程
- LangGraph：图结构，适合复杂条件分支和循环

单/多 Agent：
- 单 Agent 适用场景
- 多 Agent 系统（MAS）架构设计
- Agent 间通信与协调

**实战项目：**
- 毒舌 Gordon（单 Agent）：使用 ReAct + 工具调用
- 创意风暴（多 Agent）：主持人 + 乐观派 + 批判派 + 创意派

**前置要求：** 基础 Python 编程能力，完成第一阶段

**预估学时：** 15-20 小时

**完成标志：** 独立运行两个实战项目，能够解释 PRA 循环和 ReAct 模式

---

## 第三阶段：MCP Server 开发

**对应课程：** MCP Server 开发

**核心目标：** 理解 MCP 协议，能够开发自定义 MCP Server 扩展 AI 能力

**学习重点：**

MCP 基础：
- MCP = AI 世界的 USB 接口（统一标准，解决碎片化问题）
- MCP 的生态价值：一次开发，处处可用

三大核心能力：
- **Tools**（工具）：AI 主动触发，可有副作用
- **Resources**（资源）：只读数据，URI 标识，无副作用
- **Prompts**（提示模板）：用户选择的参数化模板
- 三者区别与适用场景

MCP Server 开发实践：
- Python MCP SDK 使用
- @server.tool() 装饰器定义工具
- @server.resource() 装饰器定义资源
- @server.prompt() 装饰器定义模板
- stdio 传输配置
- 连接到 Claude Desktop 的配置

**实战项目：** 今日运势 MCP Server
- 实现 get_fortune、get_lucky_color 等 Tools
- 实现星座信息 Resources
- 实现运势解读 Prompts 模板
- 配置到 Claude Desktop 并测试

**前置要求：** 基础 Python 编程，了解异步编程（async/await），完成第二阶段

**预估学时：** 10-15 小时

**完成标志：** 今日运势 MCP Server 成功运行，能在 Claude Desktop 中调用

---

## 第四阶段：ADE 配置与智能体开发

**对应课程：** ADE 配置与智能体开发

**核心目标：** 掌握 ADE 开发环境，通过 Skills.md 定义和扩展 AI 开发能力

**学习重点：**

ADE 体系：
- OpenCode：终端 AI 编程 Agent
- GLM-4.7 模型接入与配置
- ADE 与传统 IDE 的本质区别

Skills.md 设计：
- 文件结构：元数据、触发条件、能力说明、执行指令、输出规范
- 触发条件设计原则：精确、不歧义、覆盖主要场景
- 执行指令规范：步骤化、可操作、有标准
- 输出规范设计：格式明确、有示例

DAE 工作流：
- Discovery（发现）：技能注册机制
- Activation（激活）：意图匹配算法
- Execution（执行）：按 Instructions 执行

渐进式披露：
- L1/L2/L3 三个层次的设计逻辑
- 如何在 Skills.md 中体现不同层次

**实战内容：** 配置自定义 Skill，构建专属 AI 开发助手

**前置要求：** 了解 Agent 基本概念，完成第二、三阶段

**预估学时：** 10-12 小时

**完成标志：** 成功配置 Skills.md 并验证 DAE 工作流正常运行

## 第五阶段：安全与合规

**对应课程：** 安全与合规

**核心目标：** 了解大模型安全风险，掌握 NeMo Guardrails 护栏配置

**学习重点：**

六大安全风险：
- 越狱攻击（Jailbreak）
- 提示词注入（Prompt Injection）
- 幻觉问题（Hallucination）
- 有毒内容（Toxic Content）
- 隐私泄露（Privacy Leakage）
- 偏见与歧视（Bias & Discrimination）

NeMo Guardrails 五种护栏：
- Input Rails：过滤输入
- Dialog Rails：控制对话流程
- Retrieval Rails：过滤检索内容
- Output Rails：审查输出
- Execution Rails：监控工具调用

Colang DSL 语法：
- Colang 1.0：flow 和 message 定义
- Colang 2.0：事件驱动的状态机

**实战项目：** AI 酒吧调酒师
- 场景：AI 调酒师需要拒绝不当请求
- 配置 Input Rails 过滤不当问题
- 配置 Output Rails 确保输出合规

**前置要求：** 完成前四个阶段，了解 Agent 开发全流程

**预估学时：** 10-12 小时

**完成标志：** AI 酒吧调酒师项目成功运行，Guardrails 能有效拦截测试用例中的违规请求

## 学习建议

1. **按顺序学习**：五门课程有知识依赖关系，建议从第一门开始
2. **动手实践**：每门课程都有实战项目，一定要亲自完成
3. **做好笔记**：遇到新概念及时记录，知识点比较密集
4. **多问多测**：用课程里学到的工具测试各种边界情况
5. **关注社区**：LangChain、MCP 社区更新频繁，保持关注
