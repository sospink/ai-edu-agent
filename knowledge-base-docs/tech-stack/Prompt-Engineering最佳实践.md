# Prompt Engineering 最佳实践

## 什么是 Prompt Engineering？

Prompt Engineering（提示词工程）是设计和优化输入给大语言模型的提示词，以获得更准确、更有用的输出的技术。

## 核心原则

### 1. 清晰明确

❌ 不好的提示词：
```
帮我写点东西
```

✅ 好的提示词：
```
请帮我写一篇 500 字左右的技术博客，主题是"Python 异步编程入门"，
目标读者是有 Python 基础但不了解异步的开发者，
要求包含代码示例和实际应用场景。
```

### 2. 提供上下文

```
## 背景
我正在开发一个电商网站的后端 API

## 当前问题
用户下单时偶尔出现库存扣减不一致的问题

## 技术栈
- Python FastAPI
- PostgreSQL
- Redis

## 请求
请分析可能的原因并提供解决方案
```

### 3. 指定输出格式

```
请用以下 JSON 格式返回结果：
{
  "summary": "一句话总结",
  "key_points": ["要点1", "要点2", "要点3"],
  "code_example": "代码示例",
  "references": ["参考链接"]
}
```

## 常用技巧

### 1. 角色扮演（Role Playing）

```
你是一位有 10 年经验的 Python 高级工程师，
擅长代码优化和架构设计。
请以专业但易懂的方式回答问题。
```

### 2. 少样本学习（Few-shot Learning）

```
请将以下英文技术术语翻译成中文：

示例：
- Machine Learning → 机器学习
- Deep Learning → 深度学习
- Neural Network → 神经网络

请翻译：
- Reinforcement Learning → ?
- Natural Language Processing → ?
```

### 3. 思维链（Chain of Thought）

```
请一步一步分析这个问题：

问题：一个 API 响应时间从 100ms 增加到 2s，可能的原因是什么？

请按以下步骤分析：
1. 首先考虑网络层面的问题
2. 然后分析应用层面的问题
3. 接着检查数据库层面
4. 最后考虑外部依赖
5. 给出排查建议
```

### 4. 自我一致性（Self-Consistency）

```
请从三个不同角度分析这个技术方案的优缺点：
1. 从性能角度
2. 从可维护性角度
3. 从成本角度

然后综合三个角度给出最终建议。
```

## 高级模式

### 1. ReAct 模式

结合推理（Reasoning）和行动（Acting）：

```
问题：查询北京今天的天气并给出穿衣建议

思考：我需要先获取北京的天气信息
行动：调用天气 API 查询北京天气
观察：北京今天晴，气温 15-25°C，微风

思考：根据天气情况给出穿衣建议
行动：生成穿衣建议
输出：今天北京天气晴朗，温度适中，建议穿长袖衬衫或薄外套...
```

### 2. 结构化输出

```
请分析以下代码的问题，按格式输出：

【代码问题】
- 问题1：xxx
- 问题2：xxx

【修复建议】
- 建议1：xxx
- 建议2：xxx

【优化后代码】
```python
# 优化后的代码
```

【性能对比】
| 指标 | 优化前 | 优化后 |
|-----|-------|-------|
| 时间复杂度 | O(n²) | O(n) |
```

### 3. 迭代优化

```
第一轮：请写一个 Python 函数实现快速排序
[获得初版代码]

第二轮：请优化这个函数，添加类型注解和文档字符串
[获得改进版]

第三轮：请添加边界条件处理和单元测试
[获得最终版]
```

## 常见错误

### 1. 提示词过于模糊
❌ "帮我优化代码"
✅ "请优化这段代码的时间复杂度，当前是 O(n²)，目标是 O(n log n)"

### 2. 缺少约束条件
❌ "写一个网站"
✅ "用 React + TypeScript 写一个待办事项应用，要求支持增删改查和本地存储"

### 3. 期望过高
❌ "帮我写一个完整的电商系统"
✅ "帮我设计电商系统的用户模块，包括注册、登录、个人信息管理"

## 实用模板

### 代码审查模板
```
请审查以下代码：

```[语言]
[代码内容]
```

审查要点：
1. 代码规范性
2. 潜在 bug
3. 性能问题
4. 安全隐患
5. 改进建议
```

### 技术方案模板
```
## 需求背景
[描述需求]

## 技术约束
- 语言/框架：xxx
- 性能要求：xxx
- 其他限制：xxx

## 请求
请提供技术方案，包括：
1. 整体架构
2. 核心模块设计
3. 数据库设计
4. API 设计
5. 潜在风险和应对
```

## 总结

好的 Prompt = 清晰的目标 + 充足的上下文 + 明确的格式 + 合理的约束

记住：与 AI 对话就像与一个聪明但不了解你背景的新同事沟通，提供足够的信息才能得到想要的结果。
