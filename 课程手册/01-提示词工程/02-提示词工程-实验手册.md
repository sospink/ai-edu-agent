## 步骤 3: 理解提示词的模块化设计

### 什么是模块化？

模块化就像搭积木，把提示词拆分成可复用的小块，需要时组合使用。

### 查看语气模块

让我们查看代码中的语气模块定义：

```bash
grep -A 6 "TONE_MODULES" /workspace/courses/prompt-engineering/example.py
```

您会看到四种语气模块：
- `professional` - 专业正式
- `casual` - 轻松随意
- `humorous` - 幽默风趣
- `emotional` - 感性温暖

### 查看平台模块

查看平台风格模块：

```bash
grep -A 6 "PLATFORM_MODULES" /workspace/courses/prompt-engineering/example.py
```

包含四种平台风格：
- `xiaohongshu` - 小红书风格
- `weibo` - 微博风格
- `wechat` - 微信公众号风格
- `douyin` - 抖音风格

### 理解模块组合

这些模块可以自由组合，例如：
- 专业语气 + 微信风格 = 专业的公众号文章
- 幽默语气 + 小红书风格 = 有趣的种草笔记
- 随意语气 + 微博风格 = 轻松的微博内容

这就是模块化的威力！

### 编写代码

使用 `cat` 命令写入代码：

```bash
cat > /workspace/courses/prompt-engineering/my_generator.py << 'EOF'
#!/usr/bin/env python3
"""
我的文案生成器 - 简化版
学习提示词工程的核心概念
"""

import os
from dotenv import load_dotenv

# 加载环境变量
load_dotenv()

# 版本号（版本化原则）
VERSION = "1.0.0"

# 语气模块（模块化原则）
TONES = {
    "专业": "使用专业、正式的语气，适合商务场合",
    "轻松": "使用轻松、随意的语气，拉近与读者距离",
    "幽默": "使用幽默、风趣的语气，增加趣味性"
}

def build_prompt(topic, tone="专业", word_count=200):
    """
    构建提示词（参数化原则）
    
    参数:
        topic: 文案主题
        tone: 语气风格
        word_count: 目标字数
    """
    tone_desc = TONES.get(tone, TONES["专业"])
    
    prompt = f"""你是一位专业的文案撰写专家。

【任务】
为以下主题创作一篇文案：{topic}

【要求】
1. 语气：{tone_desc}
2. 字数：约{word_count}字
3. 结构清晰，重点突出

【输出格式】
直接输出文案内容。
"""
    return prompt

def generate(topic, tone="专业", word_count=200):
    """
    生成文案（可观测原则）
    
    返回包含元数据的结果
    """
    # 构建提示词
    prompt = build_prompt(topic, tone, word_count)
    
    # 记录元数据（可观测）
    metadata = {
        "version": VERSION,
        "topic": topic,
        "tone": tone,
        "word_count": word_count
    }
    
    # 返回结果
    return {
        "prompt": prompt,
        "metadata": metadata
    }

def test_generator():
    """
    测试函数（可测试原则）
    """
    print("=" * 60)
    print("测试文案生成器")
    print("=" * 60)
    print()
    
    # 测试1: 专业语气
    print("【测试1】专业语气")
    print("-" * 60)
    result = generate("人工智能的未来发展", tone="专业", word_count=150)
    print(result["prompt"])
    print()
    print(f"元数据: {result['metadata']}")
    print()
    
    # 测试2: 轻松语气
    print("【测试2】轻松语气")
    print("-" * 60)
    result = generate("周末去哪里玩", tone="轻松", word_count=100)
    print(result["prompt"])
    print()
    
    print("✅ 测试完成！")

if __name__ == "__main__":
    test_generator()
EOF
```

## 步骤 7: 扩展功能 - 添加关键词支持

### 任务说明

让我们为生成器添加关键词功能，这是实际应用中常见的需求。

### 修改代码

```bash
cat > /workspace/courses/prompt-engineering/my_generator_v2.py << 'EOF'
#!/usr/bin/env python3
"""
我的文案生成器 V2 - 支持关键词
"""

import os
from dotenv import load_dotenv

load_dotenv()

VERSION = "2.0.0"  # 版本升级！

TONES = {
    "专业": "使用专业、正式的语气",
    "轻松": "使用轻松、随意的语气",
    "幽默": "使用幽默、风趣的语气"
}

def build_prompt(topic, tone="专业", word_count=200, keywords=None):
    """
    构建提示词 - 支持关键词
    
    新增参数:
        keywords: 必须包含的关键词列表
    """
    tone_desc = TONES.get(tone, TONES["专业"])
    
    prompt = f"""你是一位专业的文案撰写专家。

【任务】
为以下主题创作一篇文案：{topic}

【要求】
1. 语气：{tone_desc}
2. 字数：约{word_count}字
3. 结构清晰，重点突出
"""
    
    # 添加关键词要求
    if keywords:
        keywords_str = "、".join(keywords)
        prompt += f"4. 必须包含关键词：{keywords_str}\n"
    
    prompt += """
【输出格式】
直接输出文案内容。
"""
    return prompt

def generate(topic, tone="专业", word_count=200, keywords=None):
    """生成文案"""
    prompt = build_prompt(topic, tone, word_count, keywords)
    
    metadata = {
        "version": VERSION,
        "topic": topic,
        "tone": tone,
        "word_count": word_count,
        "keywords": keywords
    }
    
    return {
        "prompt": prompt,
        "metadata": metadata
    }

def main():
    print("=" * 60)
    print("文案生成器 V2.0 - 支持关键词")
    print("=" * 60)
    print()
    
    # 测试：带关键词的文案生成
    print("【示例】产品推广文案")
    print("-" * 60)
    
    result = generate(
        topic="智能音箱新品上市",
        tone="轻松",
        word_count=150,
        keywords=["语音控制", "智能家居", "音质出众"]
    )
    
    print(result["prompt"])
    print()
    print(f"版本: {result['metadata']['version']}")
    print(f"关键词: {result['metadata']['keywords']}")
    print()
    
    print("✅ V2.0 功能演示完成！")

if __name__ == "__main__":
    main()
EOF
```

## 步骤 8: 实践提示词优化

### 提示词质量评估

一个好的提示词应该：
1. **清晰明确** - 任务描述清楚
2. **结构化** - 使用标题和列表
3. **可控制** - 通过参数调整
4. **可验证** - 输出可以检查

### 对比不同的提示词

创建一个对比脚本：

```bash
cat > /workspace/courses/prompt-engineering/compare_prompts.py << 'EOF'

对比不同质量的提示词
"""

【任务】

1. 字数：800-1000字

正文：[文章内容]

print("=" * 60)
```
