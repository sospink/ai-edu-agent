## 步骤 2: 创建第一个 Python 文件

### 理解文件和目录

在开始编程之前，我们需要了解一个基本概念：**程序是存储在文件中的**。就像您用 Word 写文档需要保存为 `.docx` 文件一样，Python 程序需要保存为 `.py` 文件。

Python 文件的特点：
- 文件扩展名为 `.py`
- 文件内容是纯文本，可以用任何文本编辑器打开
- 文件名建议使用小写字母，多个单词用下划线连接（如 `hello_world.py`）

### 使用 touch 命令创建文件

`touch` 是 Linux 系统中用于创建空文件的命令。它的名字来源于"触摸"的意思——如果文件不存在，就创建它；如果文件已存在，就更新它的修改时间。

在终端中输入以下命令创建我们的第一个 Python 文件：

```bash
touch hello.py
```

按下回车键执行命令。如果没有任何输出，说明命令执行成功了。在 Linux 中，"没有消息就是好消息"——大多数命令在成功执行时不会输出任何内容。

### 验证文件创建成功

让我们确认文件是否已经创建。使用 `ls` 命令（list 的缩写）查看当前目录下的文件：

```bash
ls -la hello.py
```

这个命令的含义：
- `ls`：列出文件
- `-l`：使用长格式显示详细信息
- `-a`：显示所有文件（包括隐藏文件）
- `hello.py`：指定要查看的文件名

您应该看到类似这样的输出：
```
-rw-r--r-- 1 opencode opencode 0 Jan 13 12:00 hello.py
```

这行信息告诉我们：
- `-rw-r--r--`：文件权限（可读可写）
- `1`：链接数
- `opencode opencode`：文件所有者和所属组
- `0`：文件大小（目前是空文件，所以是 0 字节）
- `Jan 13 12:00`：创建/修改时间
- `hello.py`：文件名

## 步骤 3: 编写第一行代码

### 认识 print() 函数

现在我们要在 `hello.py` 文件中写入我们的第一行代码。在 Python 中，`print()` 是最基础也是最常用的函数之一，它的作用是将内容输出到屏幕上。

`print()` 函数的基本语法：
```python
print("要输出的内容")
```

注意事项：
- 括号 `()` 是必须的，它告诉 Python 这是一个函数调用
- 引号 `""` 或 `''` 用于包裹文本内容（称为"字符串"）
- 中英文引号都可以，但必须成对使用

### 使用 echo 命令写入代码

我们可以使用 `echo` 命令将代码写入文件。`echo` 命令的作用是输出文本，配合 `>` 符号可以将输出重定向到文件中：

```bash
echo 'print("Hello, Python!")' > hello.py
```

这个命令的含义：
- `echo '...'`：输出引号中的内容
- `>`：重定向符号，将输出写入文件（会覆盖原有内容）
- `hello.py`：目标文件名

### 查看文件内容

使用 `cat` 命令（concatenate 的缩写）查看文件内容：

```bash
cat hello.py
```

您应该看到：
```python
print("Hello, Python!")
```

恭喜！您已经写好了第一个 Python 程序！

## 步骤 5: 扩展程序功能

### 多行输出

一个程序通常不止一行代码。让我们扩展我们的程序，输出更多内容。

首先，让我们用新的内容覆盖 `hello.py` 文件：

```bash
cat > hello.py << 'EOF'
print("Hello, Python!")
print("这是我的第一个程序")
print("Python 版本: 3.x")
print("学习日期: 2026年")
EOF
```

这里我们使用了 **Here Document**（`<< 'EOF'`）语法，它允许我们一次性写入多行内容。`EOF` 是一个标记，表示内容的结束（End Of File）。

### 运行更新后的程序

```bash
python3 hello.py
```

您将看到四行输出：
```
Hello, Python!
这是我的第一个程序
Python 版本: 3.x
学习日期: 2026年
```

### 理解程序执行顺序

Python 程序是**从上到下、逐行执行**的。这意味着：
- 第一个 `print()` 最先执行
- 然后是第二个、第三个...
- 每个 `print()` 输出后会自动换行

这种顺序执行是编程的基本原则之一。

## 步骤 6: 学习使用注释

### 什么是注释？

注释是程序中用于解释代码的文字，它们**不会被执行**。注释的作用：
- 解释代码的功能和目的
- 帮助其他人（包括未来的自己）理解代码
- 临时禁用某些代码进行调试

好的注释习惯是专业程序员的标志！

### 单行注释

在 Python 中，使用 `#` 符号创建单行注释。`#` 后面的所有内容都会被忽略：

```python
# 这是一个单行注释
print("Hello!")  # 这是行尾注释
```

### 多行注释

对于较长的说明，可以使用三引号创建多行注释：

```python
"""
这是多行注释
可以写很多行
用于详细说明代码功能
"""
print("Hello!")
```

### 实践：添加注释

让我们为程序添加注释：

```bash
cat > hello.py << 'EOF'
# ================================
# 我的第一个 Python 程序
# 作者：学习者
# 日期：2026年
# ================================

# 输出欢迎信息
print("Hello, Python!")

# 输出程序说明
print("这是我的第一个程序")

"""
下面的代码输出环境信息
包括 Python 版本和学习日期
"""
print("Python 版本: 3.x")
print("学习日期: 2026年")
EOF
```

运行程序，您会发现输出和之前一样——注释不会影响程序的运行结果。
