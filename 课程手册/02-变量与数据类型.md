# 变量与数据类型

> 学习 Python 变量定义和四种基本数据类型

## 步骤 1: 变量的定义

变量是存储数据的容器。Python 中定义变量不需要声明类型。

创建 variables.py 文件:

```bash
touch variables.py
```

输入以下代码:

```python
name = "张三"
age = 20
height = 1.75

print(name)
print(age)
print(height)
```

运行程序:

```bash
python3 variables.py
```

## 步骤 2: 变量命名规则

合法的变量名规则:

- 只能包含字母、数字和下划线
- 不能以数字开头
- 不能使用 Python 关键字
- 区分大小写

示例代码:

```python
# 正确的命名
user_name = "李四"
userName = "王五"
_count = 10
age2 = 25

# 错误的命名 (不要运行)
# 2age = 20      # 数字开头
# user-name = "" # 包含连字符
# class = ""     # 使用关键字
```

## 步骤 3: 基本数据类型

Python 有四种基本数据类型。创建 types.py 文件:

```bash
touch types.py
```

输入以下代码:

```python
# 整数 (int)
count = 100
print(count, type(count))

# 浮点数 (float)
price = 19.99
print(price, type(price))

# 字符串 (str)
message = "Hello"
print(message, type(message))

# 布尔值 (bool)
is_active = True
print(is_active, type(is_active))
```

运行程序:

```bash
python3 types.py
```

## 步骤 4: 类型检查

使用 type() 函数检查变量类型，使用 isinstance() 判断类型。

```python
a = 10
b = 3.14
c = "hello"
d = True

print(type(a))  # <class 'int'>
print(type(b))  # <class 'float'>
print(type(c))  # <class 'str'>
print(type(d))  # <class 'bool'>

# isinstance 判断
x = 100
print(isinstance(x, int))    # True
print(isinstance(x, float))  # False
```

## 步骤 5: 类型转换

创建 convert.py 文件练习类型转换:

```bash
touch convert.py
```

输入以下代码:

```python
# 转换为整数
a = int("123")
b = int(3.14)
print("转整数:", a, b)

# 转换为浮点数
c = float("3.14")
d = float(10)
print("转浮点:", c, d)

# 转换为字符串
e = str(123)
f = str(3.14)
print("转字符串:", e, f)
```

运行程序:

```bash
python3 convert.py
```

## 步骤 6: 变量的重新赋值

Python 变量可以随时改变值和类型:

```python
x = 10
print(x, type(x))  # 10 <class 'int'>

x = "hello"
print(x, type(x))  # hello <class 'str'>

x = 3.14
print(x, type(x))  # 3.14 <class 'float'>
```
