创建 convert.py 文件，练习类型转换:


要求:

参考代码:


## 步骤 4: 温度转换器

创建 temperature.py 文件，实现温度转换:

```bash
touch temperature.py
```

转换公式:
- 华氏度 = 摄氏度 * 9/5 + 32
- 摄氏度 = (华氏度 - 32) * 5/9

参考代码:

```python
celsius = 25
fahrenheit_result = celsius * 9/5 + 32
print(celsius, "摄氏度 =", round(fahrenheit_result, 1), "华氏度")

fahrenheit = 98.6
celsius_result = (fahrenheit - 32) * 5/9
print(fahrenheit, "华氏度 =", round(celsius_result, 1), "摄氏度")
```

运行程序:

```bash
python3 temperature.py
```
