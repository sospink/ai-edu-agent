## 🎯 手册特点

### 知识手册

- **理论为主** - 深入讲解概念和原理
- **图文并茂** - 使用图表和代码示例
- **实用导向** - 提供最佳实践和案例
- **循序渐进** - 从基础到进阶

### 实验手册

- **引导式** - 详细的步骤说明
- **可验证** - 每个步骤都有验证规则
- **互动性** - 提供快捷问题帮助理解
- **实操性** - 基于真实的example代码
- **完整性** - 从环境准备到总结回顾

## 🚀 使用建议

### 学习路径

1. **按顺序学习** - 课程设计有递进关系
2. **理论+实践** - 先看知识手册，再做实验
3. **动手实践** - 每个实验都要亲自完成
4. **扩展练习** - 完成实验后尝试扩展练习

### 实验环境

所有实验基于Docker环境：
- Ubuntu 22.04
- Python 3.10
- Node.js 18
- 通义千问API（OpenAI兼容模式）

**环境位置**：`/workspace/courses/`
