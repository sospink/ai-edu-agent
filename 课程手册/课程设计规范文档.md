## 🎯 课程设计原则

### 1. 环境与手册同步原则

**核心要求**: 实验环境代码和 Agent 手册必须 100% 对应

- ✅ 手册中的每个步骤都能在环境中执行
- ✅ 验证命令的路径和输出与实际一致
- ✅ 示例代码文件名和位置与手册描述匹配
- ✅ API 配置步骤在手册开头明确说明

### 2. 真实 API 调用原则

**核心要求**: 所有示例代码必须支持真实 API 调用

- ✅ 使用 OpenAI 兼容模式（通义千问）
- ✅ 从环境变量读取 API 配置
- ✅ 提供 fallback 机制（API 失败时使用模拟数据）
- ✅ 清晰的错误提示和配置指导

### 3. 渐进式学习原则

**核心要求**: 从简单到复杂，循序渐进

- ✅ 8 步实验结构（标准化）
- ✅ 每步都有明确的学习目标
- ✅ 提供验证规则和快捷问题
- ✅ 包含扩展练习和实践建议

### 4. 可验证性原则

**核心要求**: 每个步骤都可以验证

- ✅ 使用 `<!-- verify -->` 标签
- ✅ 验证命令包含完整路径
- ✅ 验证规则明确且可执行
- ✅ 提供诊断脚本辅助排查问题

## 🔧 实验环境代码规范

### 1. 代码文件结构

#### Python 示例代码模板

```python
#!/usr/bin/env python3
"""
课程X: 课程名称 - 示例标题
演示核心概念和技术要点
"""

import os
from typing import Dict, List, Any
from datetime import datetime
from dotenv import load_dotenv

load_dotenv()

class MainClass:
    """
    主类说明
    
    核心功能：
    1. 功能1
    2. 功能2
    3. 功能3
    """
    
    def __init__(self, api_key: str = None, base_url: str = None, model: str = None):
        """
        初始化
        
        Args:
            api_key: API Key（可选，从环境变量读取）
            base_url: API Base URL
            model: 模型名称
        """
        # API 配置
        self.api_key = api_key or os.getenv("OPENAI_API_KEY")
        self.base_url = base_url or os.getenv("OPENAI_BASE_URL", "https://dashscope.aliyuncs.com/compatible-mode/v1")
        self.model = model or os.getenv("OPENAI_MODEL", "qwen-turbo")
        
        # 初始化 OpenAI 客户端
        self.client = None
        if self.api_key:
            try:
                from openai import OpenAI
                self.client = OpenAI(
                    api_key=self.api_key,
                    base_url=self.base_url
                )
                print(f"✓ API 配置成功")
                print(f"  Base URL: {self.base_url}")
                print(f"  Model: {self.model}")
            except ImportError:
                print("⚠️  未安装 openai 包，将使用模拟数据")
                print("   安装命令: pip install openai")
        else:
            print("⚠️  未配置 API Key，将使用模拟数据")
            print("   请在 /workspace/.env 中配置 OPENAI_API_KEY")
    
    def core_method(self, param: str) -> str:
        """
        核心方法
        
        Args:
            param: 参数说明
            
        Returns:
            返回值说明
        """
        if self.client:
            try:
                # 调用真实 API
                response = self.client.chat.completions.create(
                    model=self.model,
                    messages=[
                        {"role": "system", "content": "系统提示词"},
                        {"role": "user", "content": param}
                    ],
                    temperature=0.7,
                    max_tokens=200
                )
                return response.choices[0].message.content
            except Exception as e:
                print(f"⚠️  API 调用失败: {e}")
                print("   使用模拟数据...")
        
        # Fallback: 模拟数据
        return f"模拟结果: {param}"


def main():
    """示例使用"""
    print("=" * 60)
    print("课程X: 课程名称 - 示例标题")
    print("=" * 60)
    print()
    
    # 创建实例
    instance = MainClass()
    
    # 示例演示
    test_cases = [
        "测试用例1",
        "测试用例2",
        "测试用例3"
    ]
    
    for i, test_case in enumerate(test_cases, 1):
        print(f"\n{'='*60}")
        print(f"示例 {i}: {test_case}")
        print(f"{'='*60}\n")
        
        result = instance.core_method(test_case)
        print(f"\n[结果]: {result}\n")
    
    print("\n💡 提示:")
    print("1. 提示1")
    print("2. 提示2")
    print("3. 提示3")


if __name__ == "__main__":
    main()
```

    echo "✓ 示例代码运行成功"
else
    echo "✗ 示例代码运行失败"

    exit 1
fi

echo ""
echo "=========================================="
echo "  ✓ 所有检查通过!"

## 🔄 开发工作流程

### 新课程开发流程

#### 第 1 步: 规划课程

1. 确定课程主题和学习目标
2. 设计核心概念和技术要点
3. 规划 8 步实验结构
4. 确定需要的工具和依赖

#### 第 2 步: 开发实验环境

1. 创建课程目录: `环境开发/courses/course-name/`
2. 编写示例代码: `example.py` 或 `example.js`
3. 参考本文档的代码模板
4. 确保支持真实 API 调用和 fallback 机制
5. 编写 README.md 说明文档

#### 第 3 步: 编写 Agent 手册

1. 创建手册目录: `课程手册/0X-课程名称/`
2. 编写知识手册: `XX-课程名称-知识手册.md`
3. 编写实验手册: `XX-课程名称-实验手册.md`
4. 参考本文档的手册模板
5. 确保第一步是 API 环境配置
6. 添加验证规则和快捷问题

1. 在容器中运行示例代码
2. 逐步执行实验手册的每个步骤
3. 验证所有命令和输出

## 🆘 常见问题

### Q1: 如何确保环境与手册同步？

**A**: 遵循以下流程：
1. 先开发实验环境代码
2. 在容器中实际运行代码
3. 根据实际运行结果编写手册
4. 逐步验证每个命令和输出
5. 使用验证脚本自动化测试

### Q2: API 调用失败怎么办？

**A**: 代码必须提供 fallback 机制：
1. 检查 API Key 是否配置
2. 尝试调用真实 API
3. 捕获异常并提示错误
4. 使用模拟数据继续演示
5. 提供清晰的配置指导

### Q3: 如何设计好的验证规则？

**A**: 遵循以下原则：
1. 验证命令包含完整路径
2. 期望输出明确具体
3. 避免过于严格的匹配
4. 考虑不同环境的差异
5. 提供诊断脚本辅助排查

### Q4: 如何编写好的快捷问题？

**A**: 遵循以下原则：
1. 与步骤内容紧密相关
2. 引导学生深入思考
3. 涵盖概念、应用、扩展
4. 每个步骤 2-4 个问题
5. 问题表述清晰简洁

### Q5: 如何测试新课程？

**A**: 完整的测试流程：
1. 在容器中运行示例代码
2. 逐步执行实验手册
3. 验证所有命令和输出
4. 运行诊断脚本
5. 运行集成测试脚本
6. 前端和 Agent 验证
